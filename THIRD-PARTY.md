This source repository does **not** bundle Tarkov.dev raster tiles generated by the builder. `tools/Prepare-Assets.ps1` downloads them locally while building.

## Icebreaker tiles

Tarkov.dev currently credits the Icebreaker interactive map to **TarkovBOT.eu** and serves the deck tiles from `assets.tarkov.dev`. The builder downloads those tiles locally.

## Labs raster tiles

Tarkov.dev serves the current `labs_v4` layers from `assets.tarkov.dev`. The older public `Labs.svg` was not used because its geometry history stops in 2023 and does not verify the newer Labs expansion.

## MapVariants / FactoryClassic

- https://github.com/LennoxP90/SPT-MapVariants
- https://github.com/LennoxP90/SPT-FactoryClassic

Their reflection APIs are read at runtime. No code or binary from either project is redistributed here.

## Leaflet CRS formula

Tarkov.dev uses `L.CRS.Simple`; Leaflet's implementation defines `scale(zoom) = 2 ** zoom`. `Prepare-Assets.ps1` mirrors Tarkov.dev's rotation + `L.Transformation` math before stitching tile images.

## Satellite style assets

DynamicMaps Extended stitches selected existing current Tarkov.dev raster tile layers for the optional Satellite artwork style. These are downloaded during the local build rather than generated from nonexistent artwork.

## Factory Classic map package

`Maps/Factory_Classic/` was supplied directly by the user for integration into DynamicMaps Extended. The supplied MapDef credits Tarkov.dev. The repository uses the supplied per-floor SVG artwork for Factory Classic; the supplied PNG derivatives are not committed to source control. The extension changes only the display name, private DynamicMaps alias, required DynamicMaps schema field, and relative image paths needed for the one-folder layout.

Third-party artwork remains subject to its original license/attribution terms and is not relicensed by the MIT license covering the extension's own code.

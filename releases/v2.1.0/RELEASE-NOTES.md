# DynamicMaps Extended 2.1.0

- Fixed the severe FPS drop reported when using the Abstract minimap.
- Fixed maps sometimes looking zoomed out, shifted or cropped after changing styles.
- Changing styles now keeps your map position, player marker and trail.
- Made Abstract maps sharper on Woods, Factory and Streets.
- Fixed switching back to the DynamicMaps Vanilla style.
- Improved map loading and memory use while keeping Satellite maps detailed.
- Maps are now included in the mod ZIP. No extra map downloads or first-launch map setup.
- Removed the old map download options from F12.

**You need:** SPT 4.1.x, DynamicMaps and MapVariants. Custom map mods must be installed separately.

**Installation:** A clean install is recommended to remove leftover files from older versions. Close the game, remove only `BepInEx/plugins/DynamicMaps-Extended`, then extract the whole `DynamicMaps-Extended-2.1.0-SPT4.1.zip` into your SPT folder. Keep your configuration and the separate DynamicMaps and MapVariants mods.

Updating v2 by extracting the whole ZIP over your existing installation and replacing files is also supported.

**Please note:** Loading a map style for the first time may still cause a brief hitch.
